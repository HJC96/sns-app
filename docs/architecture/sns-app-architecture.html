알아둘 점

  • 강의 자료의 이미지 주소, CI의 sns-devops 대상, Argo CD Application의 repoURL은 강사 계정을 가리킵니다. 모두 내 계정으로 바꿔야 하고, targetRevision은 main으로 맞춥니다.
  • GHCR 패키지가 private이면 Kind가 이미지를 받을 수 없습니다. 패키지를 public으로 바꾸거나 imagePullSecret을 만들어야 합니다.
  • Redis에는 PVC가 없어서 파드가 다시 뜨면 세션과 타임라인이 비워집니다. Postgres와 RustFS는 PVC에 저장됩니다.
  • lite 프로필은 04강을 마친 뒤 Argo CD를 지우고 진행합니다. 메모리를 확보하려는 이유 외에, selfHeal이 켜져 있으면 08강에서 kubectl scale --replicas=0으로 만든 장애가 60초 안에 복구되기 때문입니다.
